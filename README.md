# Lauren Rentz - Personal Portfolio

Welcome to the repository for my personal portfolio website, where I showcase my work at the intersection of **Kinesiology, Sports Science, and Computational Data Analysis**. This site serves as a live demonstration of my ability to apply biomechanical concepts and physical datasets to modern technology.

[🌐 View the Live Portfolio Here](https://lauren-rentz.github.io)

---

## 🎯 Project Purpose

The purpose of this project is to centralize my academic research, technical capabilities, and passion for sports science into an interactive web experience. It highlights my core competencies in:

- **Physiological Data Parsing:** Extracting and analyzing complex variables (Heart Rate, Elevation, Pace) from raw sports tracking files (e.g., Garmin `.fit`).
- **Data Visualization & Modeling:** Utilizing statistical programming, Excel pivot tables, and JavaScript libraries to turn overwhelming spreadsheets into digestible visual graphs.
- **Biomechanical Video Analysis:** Tracking specific movement patterns in sports (like cross-country skiing) to identify efficiency and technique markers.
- **Scientific Reviewing:** Evaluating fitness technology platforms and assessing AI applications within physical rehabilitation.

## 🛠️ Tools & Technologies Used

This project was built and populated using a dynamic tech stack that bridges web engineering with data science:

### Web & Deployment Stack
- **[Jekyll](https://jekyllrb.com/)**: Static site generator used for templating, routing, and Markdown compilation.
- **[GitHub Pages](https://pages.github.com/)**: Hosting platform for the continuous deployment of the live site.
- **Markdown / HTML5 / CSS3**: Core front-end structure and styling languages.

### Data Processing & Visualization
- **[Python](https://www.python.org/)** & **[Jupyter Notebooks](https://jupyter.org/)**: The backbone of my data extraction logic. Used alongside the `fitparse` library to batch process raw Garmin GPS watch data into web-friendly JSON and GeoJSON outputs.
- **[Chart.js](https://www.chartjs.org/)**: Deployed natively into the DOM to render complex, multi-axis physiological graphs interactively.
- **[Leaflet.js](https://leafletjs.com/)**: An open-source map integration used to plot extracted GPS route coordinates accurately.
- **Microsoft Web Viewer**: Used to actively embed functional `.xlsx` sheets complete with slicers and pivot tables directly onto the web without forcing a user download.
